# Cloud Computing y Cloud Robotics

Material de la materia Cloud Computing y Cloud Robotics (Facultad de Informática, UNLP), cursada 2026. El repositorio se va completando a medida que avanza la cursada.

## Estructura

- `teoria/`: diapositivas de las clases teóricas (introducción a cloud computing, AWS EC2 e internet de las cosas).
- `practica/`: enunciados de las actividades prácticas (AWS EC2, AWS IoT con Node-RED, SimuPi, Node-RED con Raspberry Pi y actividad final), con sus archivos de apoyo, las resoluciones de las actividades 1 a 4 (`actividad-N-resolucion-2026.pdf`) y el material de los talleres (`taller-N-...`: AWS EC2, IoT con Node-RED en Docker y Node-RED con Raspberry Pi).
- `apuntes-de-clase/`: apuntes propios de cada clase (`clase-1.md` a `clase-6.md` y `raspberry-pi.md`), completados con el material teórico y práctico, con preguntas para repasar al final de cada uno. Las imágenes de las diapositivas están en `img/`.
- `proyecto-final/`: robot ROBOT-02 controlado con Node-RED sobre una Raspberry Pi. Incluye el flujo de Node-RED (`flujo-final.json`) y capturas del flujo y del dashboard (`img/`).

---

Las resoluciones son propias y pueden tener errores. El material de cátedra (diapositivas, enunciados y parciales) pertenece a sus docentes y está incluido solo como referencia de estudio.
